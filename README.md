# Bayesian Spatiotemporal Modeling



Scalable Bayesian spatiotemporal modeling with INLA-SPDE for large environmental datasets.



## Methods



- Bayesian hierarchical modeling

- INLA

- SPDE spatial random fields

- Temporal RW1 effects

- Beta regression

- Spatial residual diagnostics

- HPC / Slurm workflows



## Application



The framework is demonstrated using multi-decadal mesic vegetation observations across the semi-arid western United States.
