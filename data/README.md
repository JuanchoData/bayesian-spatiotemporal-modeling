# Data



Large datasets used in this project are not included in the repository.



Key files include:



- `Mesic_TerraClimate_LONG_INLA.csv` — full long-format modeling dataset

- `Mesic_dataset_250k.csv` — fixed 250,000-row modeling sample used for the main INLA-SPDE experiments



The raw and processed datasets are excluded from version control because of their size.
